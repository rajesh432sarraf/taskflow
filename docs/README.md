## Product summary

TaskFlow helps an individual user create, organize, prioritize, search, filter and track personal tasks. Each user's tasks must remain private to that account.

## MVP principles

1. Deliver a working end-to-end application before optional enhancements.
2. Keep the stack genuinely MERN.
3. Prefer simple, readable code over unnecessary abstractions.
4. Validate and authorize every write operation on the server.
5. Keep secrets out of source control.
6. Test locally before deployment.
7. Do not claim a feature is complete until it has been tested.
